# Verification status

Snapshot of how well each feature is proven, after the swarm build, ten adversarial reviews, a re-verification round and four fix rounds. "Here" means the CI-like Ubuntu container the app was built in: it has WebKitGTK, Xvfb, a session D-Bus and GIO, but no GNOME Shell, no polkit agent, no PackageKit and no dnf5daemon.

## How it was checked

- **Automated:** 418 Rust tests (domain, application, infrastructure with fixture packages and fake D-Bus servers built from upstream interface XML, shell), 385 frontend unit/component tests, 92 Playwright specs on the mock gateways (light, dark, reduced motion), lint, `lint:copy`, type-check, bindings drift check.
- **Upstream cross-checks:** PackageKit enum values, method signatures and signals against PackageKit v1.4.0 source; dnf5daemon interfaces against the upstream XML; version ordering against 614 vectors generated by real `rpm` 4.18.
- **Real app:** the debug build run under Xvfb with xdotool: AppImage drag install, keyboard install, already-installed with Open, wrong architecture, unsupported images, damaged files, library, Trash, reconcile, second-instance forwarding, logs.
- **Adversarial review:** ten reviewers; every finding needed a failing test or a reproduction. All of their proof tests now pass.

## Open risks to check first on Fedora

1. **PackageKit 2.0.** Upstream main renamed the bus name to `org.freedesktop.packagekit1`. The adapter speaks the 1.x API. If Fedora 45 ships 2.0, the app falls back to dnf5daemon or shows "unavailable".
2. **Is PackageKit installed by default on Fedora 45 Workstation?** (ARCHITECTURE §15.2)
3. **Double polkit prompt** for unsigned local RPMs (`plan()` simulates with ONLY_TRUSTED first).
4. **Window look** with `decorations: false` + `transparent: true` on GNOME 51 Wayland (ADR-0006 spike).
5. **Licence.** The metainfo and RPM still use a placeholder (MIT).
